## Fusionner un modèle

1. Ouvrez **Fusionner**.
2. Déposez votre modèle `.docx` dans la zone prévue, ou cliquez pour le choisir. Pas de modèle sous la main ? **Télécharger un modèle d’exemple**.
3. Rocket Doc Fusion analyse le modèle :
   - chaque **variable** devient un champ du formulaire ;
   - chaque **section** devient un tableau de lignes à remplir : ajoutez, modifiez ou retirez des lignes ;
   - un modèle mal formé affiche **Modèle à corriger**, avec la liste des erreurs (voir [Écrire un modèle](/templates/write-template#erreurs-détectées)).
4. Ajustez le **Nom du document** : par défaut, le nom du modèle sans `.docx`.
5. Cliquez sur **Fusionner** : la fusion est lancée et vous arrivez sur la page du document, qui s’ouvre dans l’éditeur dès qu’il est prêt, en général en quelques secondes.

Les champs laissés vides sont remplacés par un texte vide dans le document.

## Retoucher dans l’éditeur

La page d’un document affiche l’éditeur **ONLYOFFICE**, dans le navigateur, avec toutes ses fonctions : texte, mise en forme, tableaux, images, commentaires.

| Élément | Rôle |
|---|---|
| **Modifier** / **Lire** | Passe de l’édition à la lecture seule. |
| **Enregistrer** | Demande à ONLYOFFICE d’enregistrer tout de suite : la nouvelle version apparaît quelques secondes plus tard. « Rien à enregistrer » : aucune modification en cours. |
| **Télécharger** | La dernière version, en **Word (.docx)** ou en **PDF**. |
| `v2` | La version du document. |

Sans **Enregistrer**, ONLYOFFICE enregistre de lui-même quelques secondes après la fermeture du dernier éditeur ouvert sur le document : les modifications ne sont pas perdues si vous quittez la page.

::note
Seul le propriétaire d’un document peut le modifier. Pendant la fusion, la page attend ; si la fusion échoue, elle affiche **La fusion a échoué** avec le message d’ONLYOFFICE.
::

## Versions

- La fusion crée la **version 1**.
- Chaque enregistrement depuis l’éditeur crée une nouvelle version (2, 3…).
- Remplacer le contenu par l’API (`PUT /api/documents/{id}/content`) crée aussi une nouvelle version ; les éditeurs ouverts repartent de ce contenu.

Les téléchargements portent toujours sur la **dernière** version. Le PDF de chaque version est converti par ONLYOFFICE au premier téléchargement, puis gardé en cache.

## Mes documents

**Mes documents** liste vos documents, les derniers modifiés en premier, avec leur statut et leur version :

| Statut | Signification |
|---|---|
| Fusion en cours | Le worker fusionne le modèle avec ONLYOFFICE. |
| Prêt | Le document peut être ouvert, retouché et téléchargé. |
| Échec | La fusion n’a pas abouti : survolez le statut pour voir pourquoi. |

La liste se met à jour toute seule tant qu’une fusion est en cours. Depuis chaque ligne, vous pouvez ouvrir le document dans l’éditeur, le télécharger en Word ou en PDF, ou le supprimer avec toutes ses versions.

Les documents créés en votre nom par une application (Rocket Dispatch…) apparaissent aussi, avec le nom de l’application. Vos documents ne sont visibles que par vous : les administrateurs ne les voient pas.

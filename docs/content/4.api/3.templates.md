Rocket Doc Fusion ne conserve pas de bibliothèque de modèles : chaque fusion reçoit son modèle (`POST /api/documents`). Vos modèles vivent dans votre application ou dans Rocket Cloud, comme pour Rocket Dispatch. Deux endpoints aident à les préparer.

## Analyser un modèle

`POST /api/templates/inspect`, en `multipart/form-data`, avec le modèle dans le champ `file` :

```bash [Terminal]
curl -X POST https://fusion.exemple.com/api/templates/inspect \
  -H "Authorization: Bearer …" -H "Accept: application/json" \
  -F file=@devis.docx
```

```json
{
  "variables": ["date", "numero", "client_nom", "client_adresse", "total", "expediteur"],
  "sections": [
    { "name": "lignes", "fields": ["designation", "quantite", "prix"] }
  ],
  "errors": []
}
```

| Clé | Contenu |
|---|---|
| `variables` | Les variables du modèle, hors sections, dans l’ordre du document (corps, en-têtes et pieds de page) |
| `sections` | Les lignes répétées : nom de la section et variables de la ligne (`fields`) |
| `errors` | Les erreurs du modèle, en français : section non fermée, fin sans début, section hors d’une ligne de tableau. Un modèle avec des erreurs est refusé par `POST /api/documents`. |

C’est ce que fait la page **Fusionner** pour construire son formulaire : faites de même pour proposer à vos utilisateurs les champs à remplir, ou pour vérifier un modèle avant de l’enregistrer dans votre application.

`422` si le fichier n’est pas un DOCX, `413` s’il dépasse `DOC_FUSION_MAX_FILE_SIZE`.

## Modèle d’exemple

`GET /api/templates/sample` renvoie `devis-exemple.docx`, un devis qui utilise toute la syntaxe : variables (dont une découpée en deux morceaux par Word, comme souvent), et une ligne de tableau répétée.

```bash [Terminal]
curl https://fusion.exemple.com/api/templates/sample -H "Authorization: Bearer …" -o devis-exemple.docx
```

| Variable | Exemple |
|---|---|
| `numero` | `D-2026-042` |
| `date` | `26/09/2026` |
| `client_nom` | `Société Martin` |
| `client_adresse` | `12 rue des Lilas, 69003 Lyon` |
| `lignes` (section) | `designation`, `quantite`, `prix` |
| `total` | `1 250,00 €` |
| `expediteur` | `Marie Martin` |

La démo lance Rocket Doc Fusion et ONLYOFFICE Docs avec des données prêtes à l’emploi :

- des comptes locaux et LDAP (annuaire OpenLDAP) ;
- un document d’Alice, « Devis Société Martin », fusionné depuis le modèle d’exemple dès qu’ONLYOFFICE est prêt ;
- une application externe, « Application de démo », avec un jeton connu, qui peut fusionner au nom des utilisateurs.

::note
ONLYOFFICE demande environ **4 Go de mémoire** et met à peu près une minute à démarrer la première fois. Tant qu’il n’est pas prêt, le document d’Alice reste « Fusion en cours ».
::

::tabs
  :::tabs-item{label="En local" icon="i-lucide-laptop"}
  ```bash [Terminal]
  docker compose -f compose.yaml -f compose.demo.yaml up -d --build
  ```

  Puis ouvrez http://localhost:3400 (Rocket Doc Fusion) et http://localhost:3401 (cette documentation et le changelog).
  :::

  :::tabs-item{label="GitHub Codespaces" icon="i-simple-icons-github"}
  1. Sur GitHub : **Code → Codespaces → Create codespace**. Il faut une machine de **4 cœurs et 16 Go**, pour ONLYOFFICE.
  2. Attendez la fin de la commande de démarrage (quelques minutes la première fois).
  3. Ouvrez le port 3400 (Rocket Doc Fusion) depuis l’onglet **Ports**.

  L’éditeur est chargé par votre navigateur depuis ONLYOFFICE (port 8480) : la commande de démarrage rend ce port public et donne son adresse à l’API (`ONLYOFFICE_PUBLIC_URL`). Si l’éditeur reste vide, vérifiez dans l’onglet **Ports** que le port 8480 est public, puis relancez `bash demo/codespaces/start.sh`.
  :::
::

## Comptes

| Compte | Mot de passe | Type |
|---|---|---|
| `admin@example.org` | `demo-admin-password` | local, administrateur |
| `alice@example.org` | `demo-alice-password` | local |
| `marie.martin@example.org` | `password` | LDAP, administratrice par son groupe |
| `jean.dupont@example.org` | `password` | LDAP |

## Scénarios

1. **Fusionner.** Connectez-vous avec `alice@example.org`, ouvrez **Fusionner**, cliquez sur **Télécharger un modèle d’exemple**, puis déposez ce fichier. Ses variables deviennent un formulaire et la section `lignes` des lignes à remplir. Cliquez sur **Fusionner** : l’éditeur s’ouvre sur le document fusionné.
2. **Retoucher.** Modifiez le texte dans l’éditeur, puis cliquez sur **Enregistrer** : dans **Mes documents**, le document passe en version 2.
3. **PDF.** Sur la page du document, **Télécharger → PDF** : ONLYOFFICE convertit la dernière version.
4. **Administration.** Avec `admin@example.org`, ouvrez **Administration → ONLYOFFICE** : le serveur répond, en édition Community 9.4, sans licence.
5. **Application.** Une application fusionne au nom d’Alice, avec le modèle d’exemple (`devis-exemple.docx`) :
   ```bash [Terminal]
   curl -X POST http://localhost:3400/api/documents \
     -H "Authorization: Bearer rda_demo_rocket_doc_fusion_do_not_use_in_production" \
     -H "X-Impersonate-User: alice@example.org" -H "Accept: application/json" \
     -F template=@devis-exemple.docx -F title='Devis Dupont' \
     -F 'values={"client_nom": "Dupont SARL", "lignes": [{"designation": "Maintenance", "quantite": "1", "prix": "300,00 €"}]}'
   ```
   Le document apparaît dans **Mes documents** d’Alice, avec le nom de l’application.

::warning
Les mots de passe, le secret ONLYOFFICE et le jeton de la démo sont publics : ne l’exposez pas sur Internet.
::
